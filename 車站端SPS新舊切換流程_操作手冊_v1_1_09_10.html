流程

PAO ACS人員登入› 新SPS檢查（10分鐘包含重開機）› 舊SPS備份（預估10分鐘）› 新SPS資料恢復與更新（預估30分鐘，同時間CCBE可以先安裝）› SPS更新完畢› PAM進行安裝
注意：執行過後請打勾（腳本一律用root執行）

A. 前置作業

（有執行請打勾）

(一) 新的主機檢查BIOS設定（開機按ESC或是DEL）

BIOS進入RAID設定 > Advanced > Adaptec SmartRAID 3101-4i （此部分請確認是否為4i，如果為8i請立刻停止作業）
> Array Configuration > Manage Arrays > Array A > Manage Spare Drives > Change Spare type to Dedicated > 如果顯在顯示 change to Spare type to Autoxxxx，請執行【Submit Changes】完成設定

(二) 處理RAID的部分

cd /home/sps
rm -rf HLLParam/
rm -rf XYSSParam/
注意：此處為新SPS上的操作，請先用 ifconfig 確認登入的是新機再執行。
mkdir /opt/RAID
mv /opt/msm_linux_x64_B27960.tgz /opt/RAID
cd /opt/RAID
tar zxvf msm_linux_x64_B27960.tgz
./StorMan-5.03-27960.x86_64.bin

詢問的部分都用default直接按Enter繼續

cd /usr/StorMan

確認資料夾中已安裝RAID工具

於apache_tomcat中的conf 修改 port 8443改為9453

cd /usr/StorMan/apache-tomcat/conf
vim server.xml

(三)

新的主機下：

systemctl start vsftpd.service

這樣小工具的人就可以去新SPS抓檔案（當做到新的SPS置換IP為240要記得通知小工具的人員）

(四) 打包舊的SPS將參數資料夾（HLLParam & XYSSParam）傳輸到新的SPS上

cd /home/sps
tar zcvf HLLParam.tar.gz HLLParam/
tar zcvf XYSSParam.tar.gz XYSSParam/
scp HLLParam.tar.gz sps@172.xxx.xxx.241:/home/sps
scp XYSSParam.tar.gz sps@172.xxx.xxx.241:/home/sps
備註：再次確認。此處的 rm -rf HLLParam/、rm -rf XYSSParam/ 與前置作業 (二) 的 1. 重複， 目的是在解壓縮前再次確認新SPS上沒有殘留的舊參數資料夾。
cd /home/sps
rm -rf HLLParam/
rm -rf XYSSParam/
tar zxvf HLLParam.tar.gz
tar zxvf XYSSParam.tar.gz

B. 新舊切換流程

舊SPS上執行步驟（腳本一律用root執行）

mkdir /home/sps/WL
cd /home/sps/WL
chmod +x old_station_backup.sh
chmod +x disable_service.sh
./old_station_backup.sh
./disable_service.sh
cd /home/sps
scp WL.tar.gz sps@172.xxx.xxx.241:/home/sps

（測試區為243）

複製免金鑰完成後，其他主機要連進車站SPS的都需要刪除 know_host 內的IP，然後第一次連線填寫yes

cd /home/sps/Tim
./copy_ssh.sh <新SPS IP>
vim /etc/sysconfig/network-script/ifcfg-eth0
service network restart

（將240改為243；請用ifconfig確認已修改為243）

cd /home/sps/WL
chmod +x tarUD.sh
./tarUD.sh
cd /home/sps
scp UD2.tar.gz sent.tar.gz sps@172.xxx.xxx.241:/home/sps
可看到最右邊會有兩個Port，最右邊靠機殼的Port是 ttyS4（SPS），左邊的Port是 ttyS5（PAM）

新SPS上執行步驟（腳本一律用root執行）

cd /home/sps
tar zxvf WL.tar.gz
cd /home/sps/WL
chmod +x new_station_insert.sh
./new_station_insert.sh
＊如果有跳出 Failed to stop SPSAgent.service : Unit SPSAgent.service not loaded 可以繼續做，只要後續確認 /opt/SPSAgent/SPSAgent.log 有在寫入。
如果沒有寫入，請立刻聯繫柏凱確認。
＊如果有 blob.bak 錯誤是正常的，代表沒有檔案
  • 一. s_bin.tar.gz
  • 二. Big_config.tar.gz
  • 三. Big_bin.tar.gz
  • 四. Tomcat.tar.gz（如果前面已放到/opt請搬移到/home/sps/WL中）
cd /home/sps/WL
chmod +x update_new.sh
./update_new.sh
chmod +x crontab_all.sh
./crontab_all.sh

修改完後，可將程式檔重包一份，之後只要改SPS的IP就好（CDPS固定）

先確認 /home/sps/WL 下有 change_SPSconfig.sh 與 ip_check.txt 兩個檔案：

cd /home/sps/WL
ls -l change_SPSconfig.sh ip_check.txt

兩個檔案都在，再給予執行權限並執行：

chmod +x change_SPSconfig.sh
